02 · Three agents, one room

Agents diagnose and propose.
Humans authorise.

C

Context

Ingests telemetry the moment an alert fires, checks thresholds, and links the satellite's history from room memory.

  • threshold diagnosis
  • incident history with links
  • pass countdown from orbit math
O

Options

Exactly three responses. Numbers come from the simulator, not the model, and each one declares whether it can be undone.

  • P(success), fuel, service loss
  • REVERSIBLE / IRREVERSIBLE
  • re-plans on request
A

Action

Queues the command sequence and holds it at the gate. Walks each step against telemetry and stops on a rollback.

  • awaiting_auth until signed
  • one step per checkpoint
  • post-incident report

04 · The kill-switch proof

Turn room memory off and the burn never happens.

Same anomaly, same seed. PERSISTENCE=off is the only change. From logs/comparison.md.

Persistence on
  • Incident history cited
  • One context card
  • One authorised sequence
  • Named operators on the audit link

  • No room memory
  • Duplicated context cards

05 · The audit trail is the product

"Who authorised this burn?" is one link.

Every room message, approval and command is an append-only event. Each row stores sha256(prev_hash + row), so editing history breaks the chain. These hashes are from the demo log.
